# การทำงานอัตโนมัติ (F13)

13 ต.ค. 2026: Product Owner อนุมัติให้ดึง F13 จาก P2 มาทำ (เปลี่ยนจาก Q29) และยอมรับผลทดสอบข้อมูลและรายงาน (Gate M1, M3) ให้ส่งรายงานทาง LINE อัตโนมัติได้

## ทำงานอย่างไร

launchd ของ macOS เรียก `fitbot run` ทุกวัน **08:00–20:00 ทุก 2 ชม. และตอน login** (เปิดเครื่องสายแค่ไหนก็ยังได้รายงานภายในวันนั้น)

| รอบ | สิ่งที่เกิดขึ้น |
| --- | --- |
| 08:00 | ข้อมูลครบ → ส่งรายงาน · ไม่ครบ → ส่งข้อความให้เปิดแอปเพื่อ sync |
| 10:00–20:00 ทุก 2 ชม. | ส่งรายงานแล้ว → ไม่ทำอะไร · ยังไม่ครบหลังแจ้ง 2 ชม. → ส่งรายงานบางส่วน |
| ตอน login | เผื่อวันที่เปิดเครื่องสาย ทำตามกฎเดียวกัน |

- Mac หลับอยู่ตอนถึงเวลา → launchd รันให้เมื่อเครื่องตื่น
- ระบบทำงานตามสถานะและมี lock จึงถูกเรียกกี่ครั้งก็ไม่ส่งซ้ำ (D3)

## คำสั่ง (รันจากโฟลเดอร์ fitbot-api)

```bash
./bin/fitbot schedule install            # ติดตั้ง (ค่าเริ่มต้น: ส่งรายงาน) ใช้ซ้ำได้หลัง build ใหม่
./bin/fitbot schedule install --mode collect   # เก็บข้อมูลอย่างเดียว
./bin/fitbot schedule status             # สถานะ บริการที่ต้องใช้ และการรันล่าสุด
./bin/fitbot schedule run-now            # สั่งให้รันทันที
./bin/fitbot schedule uninstall          # ยกเลิก
tail -f ~/Library/Logs/fitbot.log         # ดู log
```

ไฟล์ตั้งเวลา: `~/Library/LaunchAgents/com.fitbot.daily.plist` (working directory = โฟลเดอร์ fitbot-api เพื่ออ่าน `.env` และ `config.yaml`)

## สิ่งที่ต้องพร้อม

| บริการ | สถานะ |
| --- | --- |
| PostgreSQL | เปิดเองตอน login (`brew services`) |
| Ollama | ต้องตั้งให้เปิดตอน login ไม่อย่างนั้นรายงานจะมีแค่ตัวเลข |
| Google token | ต้อง `fitbot auth --user 1` ด้วยมือทุก 7 วัน ระบบเตือนทาง LINE ล่วงหน้า 1 วัน |
